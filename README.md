# C2G Emulator - oppdateringer

Releasene her er oppdateringer til C2G Emulator. Emulatoren henter dem selv
(«Se etter oppdatering» i vinduet, menyvalg U).

Zip-filene inneholder bare C2Gs egne filer. Leverandørenes DLL-er (BAXI, Verifone)
ligger aldri her - de følger med installasjonsprogrammet, som deles internt.
